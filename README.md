#### the desk

three tools for working with a pile of agents, all three open on my screen every day.

- **[beadside](https://github.com/thatmike1/beadside)** is where i read my agents' backlog and talk back. a local board over beads: find a thing, read what happened, leave a note the next session reads first. it stays live without twitching on every write, because the page only hears "changed" when a hash of the store's export actually moves.
- **[tally](https://github.com/thatmike1/tally)** tells me which session ate my five-hour limit. it lines the usage meter up with my local agent transcripts and splits each measured jump by the sessions' share of the cost. there's no honest formula from tokens to meter points, so it never invents one.
- **[t3 code, forked](https://github.com/thatmike1/t3code)** is the agent-thread app i live in, with the things it was missing: ctrl+tab switching, effort shortcuts, script-fed sidebar widgets, child threads nested under their parent. [click through the extras](https://t3.thatmike1.dev/) before installing anything.

#### the choosers

three public things for making a choice, no account needed.

- **[model map](https://models.thatmike1.dev/)** plots every model at every reasoning effort by intelligence score against what a whole benchmark task costs, because price per token is a bad way to pick a model.
- **[font tinder](https://fonts.thatmike1.dev/)** hides font names so you choose with your eyes. every font is sized to the same x-height, and the next card is preloaded for both a yes and a no swipe, so it's simply there.
- **[diskzokej](https://diskzokej.thatmike1.dev/)** started as my own spotify dj and became a public dial of about sixty internet radio stations. ask for a mood and one model call picks a station, from a schema that only allows stations actually on the dial.

#### different itches

- **[breakbeat loom](https://breakbeat.thatmike1.dev/)** is a browser drum loom for chopped, swung breaks. every change renders the whole loop to samples and swaps it in at the loop boundary, so a busy tab can't make it stumble.
- **[good cookie](https://goodcookie.app/)** sells privacy pages and a consent banner for $29 once, then you host them yourself. the banner catches scripts injected after load at appendChild and keeps them inert until consent.
- **[powder lab](https://powder.thatmike1.dev/)** ([source](https://github.com/thatmike1/powder-lab)) is falling sand with reacting materials and lockstep multiplayer, where only inputs cross the wire.
- **[claude-skills](https://github.com/thatmike1/claude-skills)** is the set of Claude Code skills that run my actual days, generalized once i kept reaching for them.
