#### things i built because i wanted to

- **[cc-browse](https://github.com/thatmike1/cc-browse)** reads Claude Code conversation history in a browser. full-text and semantic search across every session, including subagent transcripts. two files, no build step.
- **[claude-skills](https://github.com/thatmike1/claude-skills)** is the set of Claude Code skills that run my actual days: a morning briefing built from conversation history, an end-of-day log, an ADHD thought-structurer. started situational, generalized once I kept reaching for them.
- **[cc-bench](https://github.com/thatmike1/cc-bench)** checks whether a CLAUDE.md actually changes model behavior, instead of trusting that it does. swaps the config, runs the same prompts against a broken little repo, counts what changed. [live demo](https://thatmike1.github.io/cc-bench/).
- **[powder-lab](https://github.com/thatmike1/powder-lab)** is a falling-sand sandbox, ~14 materials that burn, flow, and dissolve at 60fps. React owns the buttons, an imperative core owns the pixels, so the simulation never touches a re-render. [play it](https://thatmike1.github.io/powder-lab/).
- **[aw-watcher-git](https://github.com/thatmike1/aw-watcher-git)** is an ActivityWatch watcher that logs which repo and branch I'm actually in, editor-agnostic. three layers of detection so it doesn't lie to me.
- **[humanizer-cz](https://github.com/thatmike1/humanizer-cz)** is a Claude Code skill that detects AI writing patterns and rewrites toward something a person would send, with a Czech grammar appendix and banned-word list.
- **[pixel-patrol](https://github.com/thatmike1/pixel-patrol)** and **[micro1-hackathon](https://github.com/thatmike1/micro1-hackathon)** are two hackathon entries submitted August 2026, a GDPR drift watchdog and an agent build, both still waiting on judges.

a couple of [Vite + React starters](https://github.com/thatmike1/vite-react-shadcn-starter) round out the list, the kind of scaffolding I got tired of rebuilding by hand.
